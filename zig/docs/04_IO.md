# Modulo 04: IO

## Proposito

El modulo IO provee operaciones de entrada/salida asincronas y cross-platform. Es la base para todas las operaciones de archivos, red, y procesos.

## Responsabilidades

- Operaciones de archivos async
- Syscalls cross-platform
- Buffers y streams
- File watchers
- Network I/O (base)

### File Operations

```zig
pub const File = struct {
    fd: FileDescriptor,
    path: ?[]const u8,

    pub fn open(path: []const u8, flags: OpenFlags) Error!File;
    pub fn create(path: []const u8) Error!File;
    pub fn close(self: *File) void;

    pub fn read(self: *File, buffer: []u8) Error!usize;
    pub fn readAll(self: *File, allocator: Allocator) Error![]u8;
    pub fn readLine(self: *File) Error!?[]u8;

    pub fn write(self: *File, data: []const u8) Error!usize;
    pub fn writeAll(self: *File, data: []const u8) Error!void;

    pub fn seek(self: *File, offset: i64, whence: SeekWhence) Error!u64;
    pub fn tell(self: *File) u64;

    pub fn stat(self: *File) Error!Stat;
    pub fn sync(self: *File) Error!void;
};

pub const OpenFlags = struct {
    read: bool = true,

    append: bool = false,
    create: bool = false,
```

### File Watcher

```zig
pub const Watcher = struct {
    // Cross-platform file watcher
    // Linux: inotify
    // macOS: FSEvents
    // Windows: ReadDirectoryChangesW

    pub fn init(allocator: Allocator) Error!Watcher;
    pub fn deinit(self: *Watcher) void;

    pub fn watch(self: *Watcher, path: []const u8, callback: WatchCallback) Error!WatchHandle;
    pub fn unwatch(self: *Watcher, handle: WatchHandle) void;

    pub const WatchCallback = fn(event: WatchEvent) void;

    pub const WatchEvent = struct {
        path: []const u8,
        kind: EventKind,
    };

    pub const EventKind = enum {
        create,
        modify,
        delete,
        rename,
    };
};
```
